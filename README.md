# Coding Interview Prep

A curated collection of coding interview problem sets and problem-solving guides.

## Contents

- Algorithms & Patterns
- Data Structures
- SQL Questions

## Study Plan Suggestion

1. Start with core patterns and concepts.
2. Solve easy questions first, then medium, then hard.
3. Practice writing clean explanations and complexity analysis.
4. Revisit missed questions weekly.

## How to Use This Repository

- Read `problem-solving-ideas.md` to understand general patterns.
- Practice from `problem-set.md` by difficulty.
- Use SQL guides in `sql-problem-solving-ideas.md` and `sql-problem-set.md`.
- Use data structure guides in `data-structure-problem-solving-ideas.md` and `data-structure-problem-set.md`.
