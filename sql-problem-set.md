# SQL Problem Set

Representative SQL interview questions by difficulty.

## Easy
1. Find all employees in a specific department.
2. Count number of orders per customer.
3. List top 5 highest-paid employees.
4. Find products with price above average.
5. Return unique city names from customers table.

## Medium
1. Find second highest salary.
2. Find customers with no orders.
3. Monthly revenue trend for last 12 months.
4. Top 3 products by category using window functions.
5. Detect duplicate emails in users table.

## Hard
1. Compute rolling 7-day active users.
2. Rank users by retention cohort and period.
3. Find median salary by department.
4. Identify gaps and islands in date sequences.
5. Build hierarchical org chart query using recursive CTE.
