# Problem Solving Ideas (Algorithms)

This guide summarizes common algorithmic patterns used in coding interviews.

## 1. Two Pointers
Use when processing sorted arrays/strings or finding pairs.

## 2. Sliding Window
Use for contiguous subarray/substring optimization.

## 3. Hash Map / Set Lookup
Use for O(1) average membership/count checks.

## 4. Binary Search
Use on sorted/searchable monotonic spaces.

## 5. Prefix Sum
Use for fast range-sum or cumulative counting queries.

## 6. Depth-First Search (DFS)
Use for traversal, backtracking, tree/graph exploration.

## 7. Breadth-First Search (BFS)
Use for shortest-path in unweighted graphs, level traversal.

## 8. Dynamic Programming (DP)
Use for overlapping subproblems + optimal substructure.

## 9. Greedy
Use when local best choices provably build global optimum.

## 10. Union-Find (Disjoint Set)
Use for connectivity, cycle detection, component grouping.

## 11. Topological Sort
Use for dependency ordering in DAGs.

## 12. Heap / Priority Queue
Use for top-k, running min/max, scheduling, merge streams.

## 13. Monotonic Stack
Use for “next greater/smaller”, histogram and span problems.

## 14. Backtracking
Use for combinatorial generation with pruning.

## 15. Bit Manipulation
Use for low-level set operations and optimization tricks.
