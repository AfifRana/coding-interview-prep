# SQL Problem Solving Ideas

This guide summarizes key SQL interview concepts and solution patterns.

## 1. Filtering & Basic Selection
- `WHERE`, `ORDER BY`, `LIMIT`

## 2. Aggregation
- `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `GROUP BY`, `HAVING`

## 3. Joins
- `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL OUTER JOIN` (where supported)

## 4. Subqueries
- Scalar, correlated, and table subqueries.

## 5. CTEs (Common Table Expressions)
- Improve readability and multi-step logic.

## 6. Window Functions
- `ROW_NUMBER`, `RANK`, `DENSE_RANK`, `LAG`, `LEAD`, running totals.

## 7. Date/Time Operations
- Date extraction, truncation, intervals, time-based grouping.

## 8. Case Expressions
- Conditional logic with `CASE WHEN`.

## 9. Deduplication & Data Cleaning
- `DISTINCT`, identifying duplicates, normalization patterns.

## 10. Performance Awareness
- Proper indexing concepts, avoiding unnecessary scans.
